# FIM

FIM la ung dung rap phim ca nhan chay tren Windows.

## Chay ung dung

Chay `FIM.exe` va ung dung se mo giao dien trong trinh duyet ung dung.

## Thanh phan

- `FIM.exe`: phien ban Windows da bien dich
- `src/Program.cs`: ma nguon ung dung
- `src/fim.ico`: icon ung dung
- `web/index.html`: giao dien web

## Du lieu rieng

Thu muc `.fim-data/` va thu muc phim co the chua du lieu ca nhan, lich su xem va file video. Hai thu muc nay khong duoc dong bo vao repository.
